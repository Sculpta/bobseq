The repository holds the processing pipeline of a BOBseq Illumina library, the benchmark against DRUG-seq and prime-seq, the
numbers behind every benchmark panel, the expression and splicing analyses of the 24-plex screen and of the comparison with
published HEK293T datasets, and the two nanopore analyses of the paper (barcode accuracy of the species-mixing runs, random
priming).

Version 0.1 is the release that accompanies the preprint.

## Layout

| Directory | Content |
|---|---|
| `pipeline/` | processing of one multiplexed BOBseq Illumina library: `run_illumina.sh` runs bobcode calling and read preparation, demultiplexing by bobcode, STAR alignment of both mates against a combined human + mouse reference, UMI de-duplication per sample, per-sample tables and a report; the steps are the modules in `pipeline/scripts/` (see `pipeline/README.md`). |
| `benchmark/` | the benchmark of the preprint (BOBseq vs DRUG-seq vs prime-seq): `run_benchmark.sh` runs the stages in order, from the public competitor data and the pipeline output to the figure tree; see `benchmark/README.md`. |
| `figures/` | the numbers behind every benchmark panel of the preprint: one values table per panel in `values/`, `replot.py`, which redraws every panel from those tables alone, `METHODS_panels.md` (how every number is computed) and a README mapping each preprint panel to its table and generator. Rendered panels are not shipped; the gene coverage examples are regenerated by `benchmark/scripts/gene_coverage_tracks.py`. |
| `expression_splicing/` | the expression and splicing analyses: the comparison of BOBseq's controls with prime-seq, BRB-seq and TruSeq (Fig. 6A, 6B, 6D, S5, S6A) and the 24-plex screen (Fig. 7A, 7C, 7D, 7E, 7F): PCA, DESeq2 against TruSeq, replicate correlation, differential splicing, SMN2 exon 7, coverage tracks with junction arcs. Inputs are the supplementary data tables of the preprint; see `expression_splicing/README.md`. |
| `data/junctions/` | the per-sample splice-junction tables (103 sample-arms, BED6 with molecule counts) and sample sheet that the junction panels (p5) are computed from; regenerated by `benchmark/extract_junctions.sh`. |
| `config/` | the run configuration of the 24-plex library (`run_24plex.json`: bobcodes, sample labels, species), the bobcode set, the index primers, the rDNA loci, the DRUG-seq plate layout and whitelist, the prime-seq sample list, the coverage sample sheets and the table of excluded wells. |
| `reference/` | `build_reference.sh`: the combined GRCh38.113 + GRCm39.113 reference (Ensembl 113 FASTA and GTF, prefixed contigs, STAR index, refFlat). |
| `nanopore/transfer_screen/` | the bobcode transfer mechanism screen (Fig. 3, S2, S3, Table S1): barcode accuracy of the species-mixing nanopore datasets (splint, poly(dT), 5' TSO and 3' TSO bobcodes) from raw reads. |
| `nanopore/random_priming/` | the random-priming comparison (Fig. 4) (gene-body coverage, 5'-3' balance, barcode accuracy, browser examples). |
| `tests/` | a 200,000-pair example of the 24-plex library and `run_smoke_test.sh` (prep and demultiplexing in about a minute; `--full` runs the whole pipeline on it). |

## Quick start

Either build the container (every tool, pinned; STAR 2.7.11b as the official static binary):

```
docker build -t bobseq:0.1 -f docker/Dockerfile .
docker run --rm -v $PWD:/work -w /work bobseq:0.1 bash tests/run_smoke_test.sh
```

or use the conda environment (`environment.yml`; STAR installed separately):

```
conda env create -f environment.yml && conda activate bobseq
gcc -O2 -o benchmark/scripts/dedup benchmark/scripts/dedup.c
bash tests/run_smoke_test.sh                                   # prep + demultiplexing of the example, counts checked
bash reference/build_reference.sh                              # once: Ensembl 113 downloads and a STAR index (about 60 GB of memory)
bash pipeline/run_illumina.sh R1.fastq.gz R2.fastq.gz config/run_24plex.json reference/combined_GRCh38.113_GRCm39.113 out/ 16
```

The driver takes one R1/R2 pair, the sequenced lane. The SRA holds the lane as 24 per-sample pairs (BioProject PRJNA1532586): concatenate the 24 R1 files into one R1 and the 24 R2 files into one R2, in the same sample order, and run the driver on that pair. See Data below for what the deposited files are.

The figures need only Python with numpy, scipy and matplotlib:

```
cd figures && python3 replot.py           # every benchmark panel redrawn from values/ into replotted/
```

The expression and splicing analyses run from the supplementary data tables of the preprint (no reads needed for most of
them): `expression_splicing/README.md`.

## Reproducing the benchmark

`benchmark/run_benchmark.sh <pipeline_out_dir> <R1.fastq.gz> <R2.fastq.gz>` fetches the public DRUG-seq and prime-seq data,
builds every arm through one frozen path (STAR with identical parameters, one read table, one molecule definition), the
per-sample BAM store, the junction tables, the coverage tables, the barcode-accuracy funnel and finally the panels and their
validation. Every stage is a script that can be run on its own and skips what exists; the working directory is
`work/` (`BOBSEQ_WORK`), the reference `reference/combined_GRCh38.113_GRCm39.113` (`BOBSEQ_REF_DIR`). The full run takes about
a day on 16 cores and needs about 500 GB of disk.

## Data

- BOBseq 24-plex library (HEK293T treatments, RAW 264.7 controls) and the nanopore species-mixing and random-priming runs: NCBI BioProject PRJNA1532586, SRA study SRP738601 (per-sample FASTQ files of the 24-plex library, one run per nanopore dataset; run accessions in `data/sra_runs.tsv`).
- The deposited 24-plex files are the read pairs of the sequenced lane split by bobcode, untrimmed and unmodified (concatenated back into one pair they are the input of `pipeline/run_illumina.sh`, see Quick start). The 4% of pairs without an assignable bobcode were not deposited, so the pipeline's total pair count is lower by that amount; the per-sample counts are identical. The deposited risdiplam files are named `Ris_dose_25nM` and `Ris_dose_500nM` (the real doses); the sample labels in `config/run_24plex.json`, and therefore the names the pipeline writes, carry the legacy unit `mM`, and the `treatments` map of that file states the dose.
- DRUG-seq: GSE176150 / SRR14730306 (Li et al. 2022).
- prime-seq: E-MTAB-10142 (Janjic et al. 2022).
- BRB-seq (method comparison only): GSE334309, the control wells of batch 5. TruSeq HEK293T runs (method comparison only): GSE296724, GSE298560, GSE181978; the run list is `expression_splicing/method_comparison/results/truseq_samples.tsv`.
- Supplementary data tables of the preprint (S1 to S11: sample sheet, PSI and junction-count matrices, Salmon / tximport gene tables, the mRNA gene set, the featureCounts matrix): deposited with the preprint; the inputs of `expression_splicing/`, to be unpacked into `expression_splicing/data/supplement_tables/`.
- Nanopore runs: one SRA run per dataset, deposited as `<chemistry>_<construct>__<YYMMDD>_BC<NN>.fastq.gz`; `nanopore/transfer_screen/fastq_manifest.tsv` lists the 186 species-mixing datasets with read count, MD5 and accession, and the 9 random-priming datasets are the `randomPriming_bob-v1` rows of `data/sra_runs.tsv`. How to run the analyses on them: `nanopore/transfer_screen/README.md` and `nanopore/random_priming/README.md`.
