# Figures: the numbers behind every panel

Reproducibility, not renders: this directory holds the values table behind every panel of the preprint (`values/`),
a script that redraws every panel from those tables alone (`replot.py`), and the definition of every number
(`METHODS_panels.md`). The rendered panels of the paper were composed from these drawings; the tables are the reference.

```
python3 replot.py                 # every panel -> replotted/<name>.svg + .png (numpy, scipy, matplotlib only)
python3 replot.py --list          # panel names
python3 replot.py --only p6b_picard_balance_native
```

## Conventions

- `native` = every method at its own read length (BOBseq 2 x 150 nt paired, DRUG-seq 52 nt, prime-seq 50 nt); `50nt` = every
  method reduced to one 50-nt read per fragment.
- Molecules = UCI (unique count identifier: well, UMI, gene, with the over-use filter and collision correction of
  `benchmark/scripts/umi_b_lib.py`). Filtered read = uniquely mapped, exonic protein-coding, human contig.
- Ribosomal-protein genes are excluded from gene counts and coverage profiles; the composition tables count them as their own class.
- Sample labels of the 24-plex wells follow `config/run_24plex.json` (the risdiplam wells carry the legacy unit `mM`; the doses are 25 nM and 500 nM).
- Colours and style: `benchmark/scripts/palette.py`; `replot.py` draws with the same palette.
